正弦测试数据（合成）
板卡 5002 请使用新版 tcp_duplex_txd1.exe，默认发送协议 TXD1/TXA1。
推荐点击“生成正弦测试”，或载入 sine_tx_payload.bin / .hex / sine_tx_values.txt。
这三个文件转换后均为 1024 B，256 组 I16/Q16，4 周期。Qt 自动添加 TXD1 帧头，
完整请求 1036 B，序号自动递增；收到 TXA1 result=0 才确认 PL 提交成功。
sine_txd1.bin：包含 TXD1 帧头，序号=1，共 1036 B。新版载入时取出载荷并自动重新编号。
测试的每个 LE32 字低16位为 I、高16位为 Q；PL 对这些字的实际解释需依据硬件逻辑。
循环发送等待上一帧回执；板端错误停止循环，超时 6 秒断开发送连接，接收继续。

下面的旧版 4096 B IQ 文件用于 Qt 接收测试，不适合板卡 5002 的固定 1024 B 载荷：
I[n] = round(12000 * sin(2*pi*n/64)), Q[n] = 0
1024 组采样，16 个周期，幅度 +/-12000，16 位有符号整数。
按 20 MS/s 解释时，信号频率为 312.5 kHz，实数正弦频谱在 +/-312.5 kHz。
每组 4 B：I 的低字节、高字节，Q 的低字节、高字节（小端）。

sine_i16q16.bin：4096 B 纯 I/Q 数据。向 Qt 接收端发送时选择原始字节协议。
sine_i16q16.hex：对应 HEX 文本，新版载入文件会解码文本为实际字节。
sine_values.txt：全部采样的十进制数值及小端字节。

sine_moni.bin：5136 B，含 16 B MONI 帧头 + 4096 B I/Q + 1024 B 零解调区。
用于发送到 Qt 接收端：新顶层布局、MONI 帧头、I16/Q16、1024 个 IQ 样本、
1024 B 解调、无 FFT；实时报波形应显示 I 正弦、Q 为零。
type=5，flags=0x0002（IQ 完整、无完整解调帧），序号=0。
同一文件重复发送不会递增序号，接收计数中的序号跳变会增加。
发送页的字节曲线显示 0-255 原始字节值；要看正弦采样曲线，请用接收端实时可视化页。
